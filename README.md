# ⏱️ Time & Space Complexity

For every important algorithm, I will try to understand:

### Time Complexity

```text
O(1)       Constant
O(log n)   Logarithmic
O(n)       Linear
O(n log n) Linearithmic
O(n²)      Quadratic
O(2ⁿ)      Exponential
O(n!)      Factorial
```

### Space Complexity

I will also analyze how much **additional memory** an algorithm requires.

> The goal is not just to make a solution work, but to make it **efficient**.
